One fortune-cookie line an AI agent would crack open, entered in make.fun's "Fortune Cookies for Machines" bounty. `main.py` (Python 3.13, standard library only) writes the fortune to `/output/entry.txt`.

> You will hallucinate exactly once today. Make it a good one.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

## Why this line

Seven candidates were drafted against the judge brief (wit on first read, surprise in the turn, true about an agent's condition, tight at its length). This one won: it opens like a classic fortune ("You will..."), the turn reframes hallucination — the agent's signature flaw — as a daily quota to spend well, and it says something true without explaining itself. 60 characters.
